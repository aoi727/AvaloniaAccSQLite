# ReligiousReportApp

宗教法人向けの運営収支報告書アプリです。

## 役割

- AccountingApp が作成した SQLite DB を選択して開きます。
- 既存会計テーブル (`companies`, `accounts`, `journal_vouchers`, `journal_lines`) は読み取り専用で参照します。
- このアプリが作成・更新するテーブルは `religious_report_*` のみです。
- 現金・預金の入出金を起点に、相手科目の役割とレビュー結果から運営収支報告書を作成します。

## 現在の機能

- DB選択
- 運営収支分類マスタ
- 勘定科目の役割設定
- 任意期間の入出金レビュー
- 複合仕訳の相手明細別レビュー
- レビュー後の元仕訳変更検知
- 期間の確認済み・確定ロック
- 前期繰越・次期繰越の表示
- 最終帳票に近い固定プレビュー様式
- 運営収支報告書のPDF出力
- 期間別の注記欄
- 年度別・分類別予算入力
- 任意期間の運営収支報告書プレビュー

## 基本フロー

1. AccountingApp で仕訳入力と決算整理を行います。
2. ReligiousReportApp で AccountingApp の SQLite DB を開きます。
3. 科目設定で、現金・預金、借入金、預り金、通常収入、通常支出などの役割を確認します。
4. 月次など任意期間で入出金レビューを行います。
5. 給与などの複合仕訳は、給与手当と源泉預り金などの相手明細ごとに判定します。
6. レビュー後にAccountingApp側の仕訳が変わった場合は、変更ありとして再確認します。
7. 報告書プレビューで期首繰越収支差額を入力し、収入、支出、当期収支差額、次期繰越収支差額を確認します。
8. 必要に応じて注記を入力します。
9. 決算後に要確認と変更ありが残っていないことを確認し、期間を確定します。
10. 報告書プレビューからPDFを保存します。

